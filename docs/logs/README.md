# Logs

This directory holds the team's AI-usage and change records. Keep entries factual, specific, and linked to the relevant commit or pull request.

## Shared templates

Do not edit `COMP41670_Project_AI_Usage_Log_Template.md` or `COMP41670_Project_DesignReport_Template.md` without group consensus. They are shared reference templates, not individual working documents.

## AI interaction logs

Each member has an `interaction-log-<name>.md` file in their own folder. Add one row for every significant use of an AI tool. Record the task, prompt summary, output, the judgement applied, changes made, verification, and resulting commit SHA. Use the AI usage-log template in this folder for the expected level of detail.

## Individual change logs

Each member also has a `change-log.md` file in their folder. Write the matching change-log entry as part of preparing the commit it describes, rather than waiting until after that commit exists. Include the branch, commit SHA when available, concise change summary, verification, and pull-request link or number. A team member may instead update the change log separately in a batch commit when that is easier.

## Project change log

Update `change-log.md` in this folder whenever a pull request is opened, substantially revised, merged, or closed. Write the entry alongside the related change whenever practical. A team member may also make a separate batch update when that is easier. Record the branch, review status, summary, resulting commit on `main`, and verification. Update the Project Progress table with completed work, the current state of `main`, next steps, and an owner.

## Before committing or opening a pull request

1. Update your AI interaction log for any significant AI use.
2. Write the matching individual change-log entry before committing, or schedule it for a separate batch update.
3. Verify the change and record the evidence.
4. Open or update the pull request.
5. Update the project change log when the pull-request status changes, alongside the related change where practical or in a separate batch update.
